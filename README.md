# GlitchOS

A neon-purple, browser-based desktop simulation built with plain HTML, CSS, and JavaScript.

## Run it
1. Download and unzip this project.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `GlitchOS`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Included apps
- File Manager: create, edit, import, export, and delete text files.
- Notepad: autosaves notes in browser storage.
- Calculator
- Browser preview (some sites block iframe embedding; use Open in new tab)
- Terminal with built-in demo commands
- Settings with wallpapers and local data controls
- Guess the Number mini-game

## Data and limitations
GlitchOS is a browser desktop simulation, not a real operating system. Files and notes are stored in the browser's local storage on the current device/browser. They do not automatically sync between devices or browsers. Export important files for backup. The browser app cannot access arbitrary device files without the user choosing an import action.
